## What I'm working on

**MACIN** is a mobile e-learning platform built with Flutter and Firebase, designed for an African context. It includes a real-time AI tutor served by a FastAPI backend, and a web admin panel (Express/EJS) used to manage content and users.

**PRM-SPAD** is a healthcare follow-up suite made of Flutter apps for patients and staff, backed by a microservices architecture (Node.js/Express/MongoDB) and an AI service in FastAPI.

## Currently learning

Machine learning and deep learning applied to real problems: sequence models (BiLSTM) and computer vision with MediaPipe and TensorFlow. I'm also working on scaling real-time (WebSocket) architectures and AI pipelines, and I'm happy to exchange ideas with people who have done it in production.
